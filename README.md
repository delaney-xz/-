# রুফাইদা অনলাইন শপ 🧸

১ থেকে ৮ বছরের বাচ্চাদের পোশাকের অনলাইন দোকান। কোনো সার্ভার বা ডেটাবেস লাগে না — GitHub Pages-এ বিনামূল্যে চলে।

## ফাইলগুলো

| ফাইল | কাজ |
|---|---|
| `index.html`, `style.css`, `app.js` | গ্রাহকের দেখার ওয়েবসাইট |
| `admin.html`, `admin.css`, `admin.js` | আপনার অ্যাডমিন প্যানেল (পণ্য যোগ/এডিট) |
| `data.js` | সব পণ্য ও দোকানের তথ্য |
| `images/` | পণ্যের ছবি |

## GitHub-এ লাইভ করার ধাপ

1. github.com এ নতুন রিপোজিটরি খুলুন (যেমন `rufaida-shop`), **Public** রাখুন।
2. **Add file → Upload files** চাপুন, এই ফোল্ডারের সব ফাইল ও `images` ফোল্ডার আপলোড করে **Commit** করুন।
3. রিপোজিটরির **Settings → Pages** এ যান। **Source: Deploy from a branch**, **Branch: main / (root)** বেছে **Save** করুন।
4. ১–২ মিনিট পর ওয়েবসাইট চালু হবে: `https://আপনার-ইউজারনেম.github.io/rufaida-shop/`
5. অ্যাডমিন প্যানেল: ঠিকানার শেষে `/admin.html` যোগ করুন।

## নতুন পণ্য যোগ করা

1. `…/admin.html` খুলুন → **নতুন পণ্য** ট্যাব।
2. ছবি, নাম, দাম, বয়স, রং, বিবরণ দিন → **সংরক্ষণ**।
3. **প্রকাশ করুন** ট্যাবে যান:
   - **সহজ উপায়:** GitHub ইউজারনেম, রিপোজিটরির নাম ও টোকেন দিয়ে **GitHub-এ প্রকাশ করুন** চাপুন। (টোকেন: Fine-grained token, শুধু এই রিপোজিটরি, *Contents: Read and write*)
   - **বিকল্প:** zip ডাউনলোড করে খুলে `data.js` ও `images` GitHub-এ আপলোড করুন।
4. ১–২ মিনিটে ওয়েবসাইটে নতুন পণ্য দেখা যাবে।

## প্রথমে যা বদলাবেন

অ্যাডমিন প্যানেলের **দোকানের তথ্য** ট্যাবে আপনার হোয়াটসঅ্যাপ নম্বর (যেমন `8801712345678`), ফোন, ফেসবুক লিংক ও ঠিকানা দিন। গ্রাহকের অর্ডার এই হোয়াটসঅ্যাপ নম্বরে আসবে। এরপর নমুনা পণ্যগুলো মুছে দিন।

## জানা দরকার

- অ্যাডমিন প্যানেল পাবলিক ঠিকানায় থাকলেও টোকেন ছাড়া কেউ ওয়েবসাইটে কিছু বদলাতে পারে না।
- টোকেন কাউকে দেবেন না। শুধু নিজের ডিভাইসে "মনে রাখুন" চালু রাখুন।
- ছবি স্বয়ংক্রিয়ভাবে ছোট করা হয়, তাই সাইট দ্রুত খোলে।
