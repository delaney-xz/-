দোকানের তথ্য

পরিবর্তন নিজে থেকেই ড্রাফটে সংরক্ষিত হয়। ওয়েবসাইটে দেখাতে "প্রকাশ করুন" ট্যাবে যান।

ওয়েবসাইটে প্রকাশ করুন

এখানে করা সব পরিবর্তন প্রথমে শুধু এই ব্রাউজারে ড্রাফট হিসেবে থাকে। দুইভাবে লাইভ করতে পারেন:

🅰️ সরাসরি GitHub-এ প্রকাশ (সবচেয়ে সহজ)

টোকেন কীভাবে বানাবেন?
  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens
  2. Generate new token → শুধু আপনার এই রিপোজিটরিটি সিলেক্ট করুন
  3. Permissions → Repository permissions → Contents: Read and write
  4. টোকেন কপি করে এখানে পেস্ট করুন। টোকেন কাউকে দেবেন না।

🅱️ ফাইল ডাউনলোড করে নিজে আপলোড

একটি zip ফাইল নামবে। এটি খুলে ভেতরের data.js ও images ফোল্ডার GitHub রিপোজিটরিতে আপলোড করুন (পুরনো data.js রিপ্লেস হবে)।
